Fedora for .net developers, ready to work in one run

Hatrick is a script you run after a fresh Fedora install. It gets you up to speed within a blink of an eye. Tick the parts you want from a single menu and the script takes care of it. No gists to hunt down, no half-remembered commands, no evening lost to setup.

Get it on GitHub See how it works

Quick start

Two lines on a fresh machine

Clone it, run it. A system update and the usual base packages are handled before anything you picked gets installed.

~/ — bash
$ curl -s https://github.com/Chuhukon/Hatrick/blob/main/hatrick.sh | bash
⚠

Run it as your normal user, not with sudo — the script asks for root only where it needs it, so everything lands in your account.

Why Hatrick

Boring on purpose

Pick from a menu

One numbered list of everything on offer. Tick what you want, press ENTER, walk away.

Plain and simple

Every plugin is a single shell file. Easy to read before you run it.

Safe to re-run

Already-installed tools are detected and skipped.

A finished desktop

Hatrick ships with a default theme. Fonts, wallpaper and dark GNOME applied in one go.
